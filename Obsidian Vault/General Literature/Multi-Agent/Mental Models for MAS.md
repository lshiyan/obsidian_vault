- The setting is sequential interaction over a finite horizon. At each timestep, the agent receives an observation $o_t$ and chooses an action $a_t$, which might be any sort of language or environmental action.
- At each timestep, we learn a mental model $q_{\omega}(z_t | h_t)$, where $z_t$ represents hidden latent variables associated with the mental states of other agents, and $h_t$ is our historical trajectory. We also learn a higher order model of another agent's environment, represented by the following equation $q_{\omega}(z_t^{(1)}, z_t^{(2)} \mid h_t) = q_{\omega_1}(z_t^{(1)} \mid h_t) q_{\omega_2}(z_t^{(2)} \mid h_t, z_t^{(1)})$, where $z_t^{(2)}$ represents all higher order information conditioned on $z_t^{(1)}$. Both are decomposed into three subspaces $z_t^{(\ell)} = \left(z_{t,\mathrm{belief}}^{(\ell)}; z_{t,\mathrm{intent}}^{(\ell)}; z_{t,\mathrm{thought}}^{(\ell)}\right)$, for $l = {1,2}$. Both models are modeled by multi-variate Gaussians $q_{\omega_1}(z_t^{(1)} \mid h_t) = \mathcal{N}\left(\mu_1(E(h_t)), \operatorname{diag}\left(\sigma_1^2(E(h_t))\right)\right)$, and $q_{\omega_2}(z_t^{(2)} \mid h_t, z_t^{(1)}) = \mathcal{N}\left(\mu_2([E(h_t); z_t^{(1)}]), \operatorname{diag}\left(\sigma_2^2([E(h_t); z_t^{(1)}])\right)\right)$. If there is available evidence $y_t$, the parameters are learned using $\omega^\star \in \arg\min_{\omega} \mathbb{E}_{(h_t,y_t)\sim\mathcal{D}}\left[D_{\mathrm{tom}}\left(q_{\omega}(z_t\mid h_t),y_t\right)+\beta\,\Omega_{\mathrm{comp}}\left(q_{\omega}(z_t\mid h_t)\right)\right]$, where $D_{tom}$ is a function that grounds the prediction against the ground truth, and $\Omega_{comp}$ limits the memorization capacity of the model.

- MAIN IDEA: Training LLMs with surprisal information rewards generalizes to unseen tasks.
- For a toy environment, a table with several options is created, with each option being binary rated on a collection of attributes. The correct option is to choose the one with the highest sum of attribute ratings. Each agent gets a subset of this table, which may overlap.
- If $R_i$ represents the rating records received by agent $i$, and $K_i$ its information record, we construct a partial rating table using information that agent $i$ has received, with all the ratings that it knows.
- Let $\Omega$ be the set of all rating tables, and $\Omega_y$ be the set of all rating tables where the best option is $y$. The posterior probability of $y$ being the best option given $K_i$ is $P(y \mid K_i) = \frac{\sum_{v \in \Omega_y} p_0(v) \prod_{(c,r) \in E_i(K_i)} \mathbf{1}[v_c = r]}{\sum_{v \in \Omega} p_0(v) \prod_{(c,r) \in E_i(K_i)} \mathbf{1}[v_c = r]}$. The team surprisal, with $K= (K_1 ...)$, is given as $\Phi(K) = -\sum_{i=1}^{n} \log_2 \bar{P}(y^\star \mid K_i)$. Essentially the likelihood that $y^*$ is the right one given all the information that the team knows. A statement $x$ is rewarded based on $\Delta \Phi(x) = \Phi(K_{\text{before}}) - \Phi(K_{\text{after}})$, the change in team surprisal upon receiving the statement.
- We also reward an agent for requesting information. The information reward of requesting a value at cell $c$ for agent $q$ is given by $I_{\operatorname{request}}(q,c) = max(\Delta \Phi(x_{q,c}), 0)$.
- To ensure that the agents actually use the messages that they receive, we introduce a reward on the answer as follows $r_i^{\text{answer}} = \bar{P}(\hat{y}_i \mid K_i) + \frac{1}{k}\sum_{o=1}^{k} \mathbf{1}[\hat{s}_{io} = s_{io}^{K}]$, where $\hat{y}_i$ is the answer given by agent $i$, $\hat{s_{io}}$ are the totals for all the other options, and $s_{io}^K$ is the reference total given the information that $i$ currently has.

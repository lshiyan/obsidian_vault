- A decision point (DP) consists of a recipient agent receiving a bundle of messages from speaker agents. Two recipients might act using different parts of this bundle, or none of it at all.
- Single agent intervention techniques fail at three levels at the MA level: 
  1. Intervention Impurity: Paraphrasing a message preserves content but might change the voice of the message or the tone, both of which can change the action distribution.
  2. Sampling noise: An agent's action choice is inherently stochastic, so sampling noise might effect the actual consequence of a message intervention.
  3. Conditional message effects: Since multiple messages arrive at a DP, we must hold all but a single one of them stable in order to find the actual effect.
- A DP is classified as the following tuple $\mathcal{B} = \left(B, c_B^t, \mathcal{M}_B^t, \pi_B\right), \qquad \mathcal{M}_B^t = \left\{M_{j \to B}^t\right\}_{j \neq B}$, where $B$ is a recipient agent, $c_B^t$ is the public history at turn $t$, $\mathcal{M}_B^t$ is the bundle of message sent by all other agents to it, and $\pi_B$ is the resultant action distribution.
- At a given DP, we can perturb a singular message to create a perturbed policy $\pi_B\left(a_B \mid \tilde{m}, \xi_{B}^{A;t}\right)$, where $\tilde{m}$ is the perturbed message corresponding to agent $A$. This message is constructed by first parsing the original message $m$ into $\Phi(m) = (s, c, r, t)$, where $(s,c,r,t)$ are the speech act, commitment, recipient, and temporality respectively. The perturbed message is then the negation of this. Essentially they want to keep the tone and everything fixed and only alter the proposition of the message.
- Since action distributions are stochastic even for fixed input, we want to know whether the resulting actions caused by the message changed are more than random noise. The perturbation score is defined as $\mathrm{FS}_{\mathrm{KL\text{-}excess}}(m,\tilde{m}) = D_{\mathrm{KL}}\!\left[\hat{\pi}_B(\cdot \mid m) \,\|\, \hat{\pi}_B(\cdot \mid \tilde{m})\right] - \hat{\mu}_{\mathrm{noise}} - 1.5\hat{\sigma}_{\mathrm{noise}}$, where the mean and standard deviation terms account for random noise. If this score is above a certain threshold, then that message was influential in the action distribution.
- To determine the driver-regime of a given DP, we count the number of scores such that the score is above a certain threshold. If the number is 0, then there's no-driver, if it's 1 or the max score dominates the second max, it's a single driver, and it's mixed otherwise. Since it's more likely that at least one threshold is above 0 as the number of messages increases, we can adjust the threshold based on the number of interventions done.

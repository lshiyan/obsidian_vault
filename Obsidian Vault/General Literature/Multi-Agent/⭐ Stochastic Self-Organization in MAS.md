- MAIN IDEA: Self-organization in agent swarms has the potential to dynamically suppress incorrect responses while increasing the influence of correct ones.
- Due to the stochastic nature of LLM responses, any fixed per-task topology is ultimately brittle. Different responses / samplings may cause the same topology to be suboptimal today when it was optimal yesterday.
- The setting is a series of agents, with a dynamic directed graph representing the communication topology at a given step. The nodes represents agents with a given LLM backend, and the edges represents two agents that are capable of coordinating.
- At the first stage, we independently ask each agent to generate a response to a given user query, and we embed each of these user queries using the same lightweight embedder. 
- Given a series of responses, we want to determine how much each response adds to the collective response, we do this through Shapley values. For agent $n$, the Shapley value of its response is $\phi_n = \sum_{S \subseteq [N] \setminus \{n\}} \frac{|S|!(N-|S|-1)!}{N!} \left[v(S \cup \{n\}) - v(S)\right]$. Here $v(s)$ is the utility function, and this is essentially of way of studying how much agent $n$'s response changes the overall utility. Since this requires $2^N$ computations, which is exponential in the number of agents, we approximate the Shapley value of a given agent by its cosine similarity to the average response embedding $\phi_n \rightarrow \psi_n = cos(r_n, r_{avg})$.
- Given a connected graph $G_t$, we want to determine $G^{t+1} = (V, E^{t+1})$ that determines the communication topology in the next round. We first computer $\psi_n^{t+1}$ for each agent, and then pairwise similarities $S_{n,m}^t$, which is the cosine similarity between agent responses. - After T rounds, we generate our final response as follows. First we find the contribution-weighted centroid response $r_{\text{centroid}}^{(T)} = \frac{\sum_{n=1}^{N} \psi_n^{(T)} r_n^{(T)}}{\sum_{n=1}^{N} \psi_n^{(T)}}$. Among the responses from round $T$, we choose the one that is most similar in embedding to the centroid response, and choose that as our final response.
- It can be shown that this self-organization amplifies signals from correct responses while suppressing noise.

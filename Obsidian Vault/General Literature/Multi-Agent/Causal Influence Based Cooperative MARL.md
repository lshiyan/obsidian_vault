- Centralized Training with Decentralized Execution is a common solution to non stationary environments. A centralized controller has access to all agent states for training updates, but actual action execution is still dependent only on an agent's observed state.
- The issues with centralized training are that they assume independence of policies, such that a joint policy is simply the product of each independent one, disallowing cooperative dynamics from being learnt; also optimizing decentralized policies is difficult due to the stochastic and sparse signal that environment rewards tend to give.
- We are operating in a decentralized POMDP, using this CTDE approach. A causal graphical model (CGM) is represented as a DAG. Each node has a random variable $X_i$, and an edge $(v_i, v_j)$ represents that $X_i$ causes $X_j$. The distribution of all variables up to $v$ can be represented as $p(X_1, \ldots, X_v)=\prod_{i=1}^{v}p_i\left(X_i \mid \operatorname{PA}_G(X_i)\right)$, where $\operatorname{PA}_G(X_i)$ are all the parent r.v.'s of node $i$ in the graph. A multi agent CGM is used to model the dynamics of a state transition at time $t$ ![[Pasted image 20260930200825.png]]where an agent's action $A_t^i$ will modify their next observable state $S_{t+1}^i$.
- An agent $i$ can affect an agent $j$ if under all actions that agent $i$ can do, there exists an edge between $A_t^i$ and $S_{t+1}^j$. They have a lemma that shows that if a single intervention action is independent of the next state, then it is true for all intervention actions, and vice versa. They use conditional mutual information as a way of determining independence, and if CMI > 0, then there is dependence on agent $i$'s action $CI_{ij} := I\left(S_{t+1}^j; A_t^i \mid S_t^i\right)$.

- MAIN IDEA: Latent communication using one-shot rollout can produce competitive results with text-based communication, while improving output tokens needed and latency.
- The task is sequential collaboration among agents. At each task $q$, each agent receives a textual input $x_i$ and $M_{i-1}$, which is a message from its predecessors. If $S_i$ is the state of agent $A_i$ after processing a message, we can write $S_i = A_i(x_i, M_{i-1})$ and $M_i = \Gamma_i(S_i)$, where $\Gamma_i$ is a generic message construction. The final answer $\hat{y} = A_N(x_N, M_{N-1})$.
- In traditional trajectory based latent communication, we have that latent states are constructed using a latent trajectory, and then the message $M_i$ is constructed from these latent states. We want to learn a writer $M_i = W_{\phi;\theta^*}(S_i)$, where $\phi$ parameterizes the writer, and $\theta^*$ represents the parameters of the language model backbone.
- We factorize the current state into a continuation seed and a context bank $S_i = (R_i, C_i)$. 
- The continuation seed represents the current computational state of the backbone. If $F$ is the position of the hidden state of the last input token, then the continuation seed concatenates these hidden states across all transformer layers $R_i = [h_{i, F}^{l_1}...]$.
- The context bank $C_i$ represents the context that the backbone has when generating output tokens, $C_i = {(K_{i,n}^l, V_{i,n}^l)}$. Here, $l$ is an index representing the transformer layer, and $n$ is an index representing any maintained context position in the input.
- In autoregressive continuation, $R_i$ and $C_i$ are used sequentially. The trajectory expands the current $R_i$ into future states, and contextualizes these states into the new prefix memory $C_i$. Since we are removing autoregressive rollout, these two functions need to be implemented differently.
- In actual rollout, one must autoregressively generate future positions in latent space. The paper introduces a series of $B$ learnable latent 'slots', which act as queries over the continuation seed $R_i$, $O = [o_1, o_2, \ldots, o_B] \in \mathbb{R}^{B \times d_s}$. We then perform cross attention using these queries as $E_i = g_{\phi}(O, R_i)$, where $g_{\phi}$ is a cross attention module.
- Once we have these $E_i$, which the embeddings for these $B$ continuation positions, we feed them into the frozen backbone as virtual tokens, while supplying the KV cache from $C_i$. The keys and values produced from this forward pass then constitute the message $M_i = \left\{ \left(\hat{K}_{i,j}^{l}, \hat{V}_{i,j}^{l}\right) \right\}$.
- To actually train this writer, we use the backbone to perform latent state rollout, and obtain teacher state targets $M_i^*$ using this rollout (as opposed to the one shot continuation state in the previous section). The loss function for the writer is a squared error term $\mathcal{L}_{KV} = \frac{1}{BL} \sum_{\ell=1}^{L} \sum_{j=1}^{B} \left( \left\| \hat{K}_{i,j}^{\ell} - K_{i,j}^{\ell,\star} \right\|_F^2 + \left\| \hat{V}_{i,j}^{\ell} - V_{i,j}^{\ell,\star} \right\|_F^2 \right)$, where the hat terms represent the student states, and the $*$ terms represent the teacher state.

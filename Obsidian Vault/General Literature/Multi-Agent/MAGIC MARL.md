- MAIN IDEA: Influence of specific agents are better defined using a temporally extended sequence of actions.
- The issue with CTDE is that is optimizes a joint policy, but it is still unclear how a local action influences the collective reward.
- For counterfactual action rollout, define the action of agent $i$ at time $t$ as $a_t^i$, and the actions of the other agents as $a_t^{-i}$. The factual branch keeps the actual state $(a_t^i, a_t^{-i}, s_t)$, while the counterfactual branch takes on $K$ alternative actions $\left\{\left(a_{i,t}^{k},\,a_{t}^{-i},\,s_t\right)\right\}_{k=1}^{K}$.  Action rollouts are done with a learned neural model $s_{t+1} = f_{\phi}(s_t, a_t)$, where $a_t$ is the full joint policy. 
- At a rollout horizon of $h$, we can compute the distance between the factual rollout state of agent $j$ and the counterfactual ones as follows $d_{j,h}^{(k)}=\operatorname{dist}\!\left(z_j\!\left(\hat{s}_{t+h}^{\,f}\right),z_j\!\left(\hat{s}_{t+h}^{\,k}\right)\right)$, where $z_j$ takes in a full centralized state and returns the normalized observed state of agent $j$. These differences are averaged over $K$ counterfactual actions for the horizon $h$ $d_{j,h} = \frac{1}{K} \sum_{k=1}^{K} d_{j,h}^{(k)}$. The action effect / influence reward is then taken as a weighted average over rollout length and effect on other agents $\tilde{c}_i(t) = \sum_{h=1}^{H} w_h \frac{1}{N-1} \sum_{j \neq i} d_{j,h}$.
- This effect reward only measures how much an action actually changes the future trajectories of the other agents, not whether this is actually beneficial or not. To fix this, we first calculate the advantage relative only to the environmental reward value function $A_{\mathrm{team}}^{\mathrm{ext}}(t) = r_t^{\mathrm{ext}} + \gamma V_{\omega}^{\mathrm{ext}}(s_{t+1}) - V_{\omega}^{\mathrm{ext}}(s_t)$. They then gate this value by a bounded monotone function $g$ $\kappa(t) = g\left(A_{\mathrm{team}}^{\mathrm{ext}}(t)\right)$. They use this as a scaling factor for the actual influence reward $r_{i,t}^{\mathrm{int}} = \lambda_{\mathrm{int}} \kappa(t) c_i(t)$, such that only actions that lead to a positive advantage are rewarded. The total reward is then just a sum of this intrinsic reward and an external environmental reward.

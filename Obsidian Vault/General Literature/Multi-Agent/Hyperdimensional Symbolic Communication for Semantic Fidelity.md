- MAIN IDEA: We can use high dimensional vector spaces to ensure both message robustness and easy decoding in multi-agent communication.
- Semantic fidelity is the extent to which meaning between agents can be transmitted and understood accordingly. This is broken up into two types, transmission fidelity, which ensures that messages are robust under noisy channels, and conversation fidelity, which means that receivers are able to decode the meaning of a given message. 
- High dimensional vectors are a good start for this, since it high dimensions, two random vectors are very likely to be orthogonal, satisfying the transmission fidelity requirement, and invertible algebraic operations satisfy the requirements of conversation fidelity.
- We operate in a decentralized POMDP, where our aim is to learn a joint policy that maximizes the expected group reward.
- HDC consists of two operations, bind and bundle. Bind essentially sets a variable to its value "red bind color" sets color = red. Bundle adds together multiple concepts into a singular vector, so "color bundle circle" is a vector that represents a red circle.
- We represent the messages as (entity, attribute, value) pairs in high dimensional space. Attribute vectors are randomly initialized and processed using Schmidt orthogonalization to preserve orthogonality. For continuous value vectors, we can discretize the range of possible values of an attribute, and encode $HV_v$ as a deterministic function of $v$ in the value range. The final message for an observation $O$ is then $HV_O = \bigoplus_{j \in E} \left[ HV_{id}^{j} \otimes \bigoplus_{attr \in A} (HV_{attr} \otimes HV_v) \right]$. We also encode actions in this high dimensional space.
- At the receiver end, a receiver $i$ binds a message with its own ego vector (a vector that represents its current observations), to form a context-aware message encoding.
- When receiving messages, environmental perception is supplemented when different agents have dissimilar observations to you. Action selected is supplemented when different agents have similar observations to you. If we denote by $\alpha$ the vector of similarity scores between a receiver's context message and an incoming message, we can construct fused messages representing both observations and actions $M_i^o = \sum_{j=1}^{N} \dot{\alpha}_{i,j} * (m_i^o \otimes m_j^o), \quad M_i^a = \sum_{j=1}^{N} \alpha_{i,j} * (m_i^a \otimes m_j^a)$. These messages are then used to produce decisions through a local Q-network.

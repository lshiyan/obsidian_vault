- MAIN IDEA: The use of explicit reward for influential behavior increases the efficiency of multi-agent communication.
- Intrinsic motivation is defined as reward functions that encourage exploration in RL, often without explicit reward from the environment.
- Sequential social dilemmas are partially observable multi-agent games with game theoretic payoff structures. Generally the collective agent reward is maximized if they cooperate, since in the short term greedy behavior will maximize reward.
- The setting is a Markov game $\langle S, T, A, r \rangle$, $S$ is the state space, $T$ is the transition function, $A$ is the joint action space, $r$ is the reward function. The game in this paper is partially observable, and they use asynchronous advantage actor critic to train the policies $\pi^k$.
- The social influence modifies the reward function of an agent as $r_k^t = \alpha e_k^t + \beta c_k^t$, where the first and second term represents environment and influence rewards respectively.
- Given agents $j$ and $k$, agent $j$ can condition his action on the action of agent $k$ at a given timestep, namely $p(a_t^j \mid a_t^k, s_t^j)$. Given a counterfactual (one that the agent did not take) action $\tilde{a}_k^t$, it is possible to define a similar action distribution on agent $j$, $p(a_t^j \mid \tilde{a}_t^k, s_t^j)$. If we sample the counterfactual actions, we can marginalize $j$'s action distribution based on $k$'s actions: $p(a_t^j \mid s_t^j) = \sum_{\tilde{a}_t^k} p(a_t^j \mid \tilde{a}_t^k, s_t^j) p(\tilde{a}_t^k \mid s_t^j)$. The causal reward for agent $k$ is then given as the KL divergence between $j$'s conditioned policy and marginalized policy $c_k^t = \sum_{\substack{j=0 \\ j \neq k}}^{N} \left[ D_{\mathrm{KL}} \left( p(a_t^j \mid a_t^k, s_t^j) \,\|\, p(a_t^j \mid s_t^j) \right) \right]$ .
- Note that this is related to the notion of mutual information. The singular aspect of the causal reward related to agent $k$ influencing agent $j$ is given by $D_{\mathrm{KL}} \left( p(a_t^j \mid a_t^k, s_t^j) \,\|\, p(a_t^j \mid s_t^j) \right)$. The mutual information between the distribution $A_t^k$ and $A_j^t$, namely the action distributions of the agents at a given timestep, is given by $I(A_t^k ; A_t^j) | s) = \sum_{a^k} p(a^k \mid z) D_{\mathrm{KL}} \left[ p(a^j \mid a^k, z) \,\|\, p(a^j \mid z) \right]$. By taking multiple trajectories corresponding to different actions $a^k$, we obtain a Monte-Carlo approximation of the mutual information $I(A^k; A^j \mid z) = \mathbb{E}_{\tau} \left[ D_{\mathrm{KL}} \left( p(A^j \mid A^k, z) \,\|\, p(A^j \mid z) \right) \middle| z \right] \approx \frac{1}{N} \sum_{n} D_{\mathrm{KL}} \left( p(A^j \mid a_n^k, z) \,\|\, p(A^j \mid z) \right)$. This means the causal rewards benefits agents who maximize the mutual information between them and other agents' action distributions.

- For the next experiment, they equip the agents with a standard communication channel. Formally, at each timestep $t$, agent $k$ chooses from a predefined set of messages $m_k^t$, which form a message vector $m_t = [m_t^0, m_t^1, \ldots, m_t^N]$. This message vector is then fed into the inputs of all of the agents in the following timestep. They augment the policy network of each agent to learn a separate message policy head as well. Here, they move to only training the environmental policy with an environment reward, and move the causal reward to the message policy. The reward is given similarly to the previous part $c_t^k = \sum_{\substack{j=0 \\ j \neq k}}^{N} \left[ D_{\mathrm{KL}} \left( p(a_t^j \mid m_{t-1}^k, s_t^j) \,\|\, p(a_t^j \mid s_t^j) \right) \right]$. Interestingly, it is actually most efficient to train the communication policy with no external reward, namely $\alpha=0$ in the picture below.

- For their experiments, they use speaker consistency to denote a metric that relates to the entropy of $p(a^k|m^k)$ and vice versa. This metric should be high if the symbols are very related to the actions that the agent takes, and vice versa. They also track instantaneous coordination, which is related to the mutual information between messages and actions $IC = I\left(m_t^k; a_{t+1}^j\right)$, and between actions and actions $IC = I\left(a_t^k; a_{t+1}^j\right)$. (This metric is only taken through the maximum of two agents to see if they're communicating.)![[Pasted image 20260913125711.png]]
  Results show that baseline agents show almost no instantaneous communication, as expected. The "influential moments" mean timesteps where the influence is higher than the mean influence, which occur around 10% of the time. Clearly the agents only listen when communication is beneficial. They also found that higher influence rewards positively correlate with higher individual rewards, i.e. better communication leads to higher rewards.
- This sort of causal influence reward requires agents have access to the action policies of the other agents. This is not always the case, so we can learn to predict the others actions as well. ![[Pasted image 20260913131213.png]]
  We swap out the message policy head for a separate network that predicts the next actions of the other agents using the current actions. An agent that imagines itself taking actions that it did not take can assign the highest reward to actions that would (by its estimation), have changed the other agents distributions the most. (Not sure why this isn't formalized in the paper). This influence reward is only given between agents that are in each other's FOV. The highest influence agents achieve the highest reward in this architecture, even compared to the previous two. This is a compelling result, as it shows that visibility of the others' policies are not necessary for the highest rewards.
- Note that in order to avoid cyclic dependencies, they choose a disjoint set of influencer and influencee agents in order to make sure that the causal influence can only go one way. In the MOA case, this is not a problem, and the temporal nature of the learning means that conditioning on previous states is fine.

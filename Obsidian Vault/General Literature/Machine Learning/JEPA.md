- In traditional computer vision, there are usually two types of approaches for self supervised learning from images, invariance based methods, and generative methods. Invariance based methods aim to train an encoder to provide similar embeddings for images that have various augmentations performed on them. These embeddings can learn high level semantic concepts, but are generally biased and focus a lot on the types of augmentations performed, which can vary across tasks. Denoising methods can generalize better, but often learn representations that do not have as much semantic information.
- Traditional joint-embedding architectures learn to output similar embeddings for similar images. Generative architectures learn to directly generate a signal $y$ from the embedding of a similar signal $x$. The JEPA architecture learns to predict the actual embeddings of $y$ from a similar embedding $x$, using additional latent variables. This way it is non-generative, since the predictions are made in embedding space.
- JEPA works as follows. Given an image $y$, we take an arbitrary section of it as a context block. We then want to sample various non-overlapping sections of it as target blocks, and we want to predict the embeddings of the target blocks given the context block. The loss is just the L2 distance between the embeddings.

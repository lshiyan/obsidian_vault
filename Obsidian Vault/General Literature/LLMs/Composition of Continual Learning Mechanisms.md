- MAIN IDEA: Using multiple continuing learning mechanisms in tandem will increase performance as opposed to just one.
- Given a language model $p_{\Theta}$, a set of tasks $T$ which each contain training examples $D_t$, each consisting of a question and answer pair, the supervised SFT loss function is $L_t^{\mathrm{SFT}}(\Theta) = -\mathbb{E}_{(x,y)\sim D_t} \left[\log p_{\Theta}(x,y)\right]$.
- They augment the loss function using three separate anchors so that the full parameterization is given as $\Theta_t = \operatorname*{arg\,min}_{\Theta} \left[ L_t^{\mathrm{SFT}}(\Theta) + R_t^{D}(\Theta) + R_t^{F}(\Theta) + R_t^{W}(\Theta) \right].$ 
- Data anchor: During training, the model is trained on replayed sequences representing earlier tasks. If $Q_{t-1}$ is the distribution of these sequences, and $l_D$ is the loss function, the anchor term is given by $R_t^{D}(\Theta) = \mathbb{E}_{z \sim Q_{t-1}} \left[ \ell_D(\Theta, z) \right].$ In the paper, before each task after the first, they use a frozen model to generate prior task examples that they mix into the current minibatch.
- Function anchor: The current-task outputs are constrained by the distribution of a reference model. If $\mu_t$ is the distribution of current tasks examples $x$, and $q_{t-1}(\cdot|x)$ is the reference distribution for $x$, and $d$ is the distance between them $R_t^{F}(\Theta) = \mathbb{E}_{x \sim \mu_t} \left[ d\left( q_{t-1}(\cdot \mid x), p_{\Theta}(\cdot \mid x) \right) \right].$ 
- Weight anchor: We set a group of weights $\vartheta$ as weights that are tracked by our weight anchor, and denote an importance metric as $H_{t-1}$, we have that $R_t^W(\Theta) = \frac{1}{2} (\vartheta - \vartheta_{t-1}^{*})^{\top} H_{t-1} (\vartheta - \vartheta_{t-1}^{*})$. We essentially want to punish the model for having drastic changes between important weights.
- While these anchors constrain the current weight updates, it is still necessary to determine which weights to actually change. There are two ways of structuring LoRA. If $W_0$ is the initial weight matrix, then shared LoRA reuses the same initial weight matrix throughout each iteration $W_t = W_0 + \rho A_t B_t$ while shared lora uses new $A, B$ matrices for each task $W_t = W_{t-1} + \rho A_t B_t$.
